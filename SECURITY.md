# Security Policy

Vantrel is in early development and is not production trading software.

## Reporting A Vulnerability

Do not open a public issue for suspected vulnerabilities.

Report security concerns privately to the repository owner through GitHub. Include:

- Affected files or components
- Steps to reproduce
- Potential impact
- Whether secrets, credentials or private data may be involved

## Secrets And Sensitive Data

Never commit:

- API keys, passwords, tokens or certificates
- Employer code or confidential material
- Proprietary datasets
- Licensed market data without redistribution rights
- Centrica-specific source code or confidential concepts

If a secret is committed, revoke it immediately and rotate any affected credentials.
