# Licensing

Vantrel currently uses the Apache License 2.0.

This choice is intended to support a future open-source release while allowing broad use of the project.

Dependency rules:

- Prefer permissive licenses such as Apache-2.0, MIT and BSD.
- Review copyleft dependencies before adding them.
- Do not add dependencies with unclear, proprietary or incompatible licenses.
- Do not commit proprietary datasets or market data without redistribution rights.

Licensing decisions can be revisited through an Architecture Decision Record.
