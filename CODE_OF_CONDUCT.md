# Code of Conduct

Vantrel contributors are expected to work professionally and constructively.

## Expected Behavior

- Be respectful in technical disagreement.
- Focus feedback on code, design, documentation and operational impact.
- Prefer clear evidence over status or volume.
- Credit others' work.
- Respect confidentiality, licenses and data ownership.

## Unacceptable Behavior

- Harassment, threats or discriminatory language.
- Publishing private information without permission.
- Introducing proprietary or confidential material into the project.
- Repeated disruption of technical discussions.

## Enforcement

Maintainers may remove comments, close issues or pull requests, or restrict participation when behavior conflicts with this code of conduct.

Security issues should be reported through the process in [SECURITY.md](SECURITY.md), not public issues.
